1. 개요

  • 목적: KSSCOOP 홈페이지의 디자인 방향, 화면 구성 및 시각 기준 정의
  • 범위: 메인 페이지 1식 (소개, 가치, 함께하는 방법, 경영공시, 문의 포함)
  • 근거: 2026. 10. 21. 기관 요청 메일 및 첨부 자료(2021년 홈페이지 자료, 신규 CI)
  • 산출물: 디자인 정의서(본 문서), 검토용 시안

2. 기획 방향

  • 회사 이미지 중심의 간결한 구성
    • 한 페이지 안에서 모든 정보 확인 가능하도록 구성
  • KSSCOOP 명칭 및 신규 CI 전면 사용
    • 정식 법인명(한국스포츠교육희망나눔 사회적협동조합)은 소개 및 하단에 병기
  • 상세 연혁 및 세부 사업 내용 미게재
  • 확인된 정보만 게재
    • 미확정 항목은 ‘기관 확인 후 등록’으로 표기
    • 수치, 실적, 후기 등 근거 없는 내용 미포함

3. 디자인 콘셉트: 센터 코트

  • 실제 농구 경기장 바닥을 무대로 삼아 스포츠 단체의 정체성 표현
  • 첫 화면 배경: 남색 나무 바닥 위에 골밑 영역(페인트존, 자유투 원, 3점 라인, 백보드)을 국제 규격(FIBA) 비율로 표시
  • 코트 표시는 바닥에 칠해진 선처럼 은은하게 처리하여 배경 역할로 한정
  • 왼쪽에 로고, 대표 문구, 설명, 버튼을 정렬하여 첫 화면 안에서 핵심 정보 확인 가능
  • 페이지 진입 시 코트 선이 그려지고 문구가 차례로 나타나는 효과 1회 적용 (움직임 최소화 설정 시 미적용)
  • 첫 화면에 시각적 강조를 집중하고, 이하 영역은 같은 소재(남색 바닥·금색 선)로 통일감 유지

4. 화면 구성

순서영역주요 내용비고
1첫 화면로고, 대표 문구, 설명, 버튼(소개·문의)문구 가안 3종
2소개소개 문단, 정식 법인명기관 문장으로 교체 예정
3강조 문장금색 코트 선 이미지 위 대표 문장 1개문구 가안 3종
4하는 일세 가지 가치 (건강한 사회, 행복한 교육, 모두의 스포츠) 및 이미지2021년 자료 키워드 활용
5함께하는 방법교육 문의, 기관 협력, 후원 안내 (문의 영역 연결)안내 범위 확인 필요
6경영공시연도별 자료 목록 (기부금 모금·활용실적, 결산·경영공시)자료 등록 전
7문의이메일, 전화, 주소연락처 확인 필요
8하단법인 정보, 경영공시·개인정보처리방침 링크법인 정보 확인 필요

첫 화면

  • 배경: 나무 바닥과 골밑 코트 표시
  • 왼쪽 정렬: 로고, 대표 문구, 설명, 소개·문의 버튼

소개

  • 소개 문단과 정식 법인명 병기

강조 문장

  • 금색 코트 선 이미지 전면 배경
  • 대표 문장 1개 크게 표시

하는 일

  • 가치별 이미지(농구공, 호루라기, 운동화)
  • 굵은 제목과 한 문장 설명
  • 세부 사업명 미표기

함께하는 방법

  • 교육 문의, 기관 협력, 후원 안내 3개 경로
  • 선택 시 문의 영역으로 이동

경영공시

  • 연도 선택 후 자료 목록 표시
  • 회원가입 없이 열람·다운로드
  • 현재 목록은 시안용 빈 상태

문의 및 하단

  • 연락처 3종 표시, 별도 입력 양식 없음
  • 하단 법인 정보 및 링크
  • 휴대폰 화면: 세로 한 줄 배치로 자동 전환
  • 메뉴: 우측 상단 버튼으로 열림
  • 검수 기준 폭: 360 · 390 · 430 · 768 · 1440px

5. 시각 기준

가. 색상

남색#0F1F3D · 주 바탕색
짙은 남색#0A1428 · 상단·하단
금색#E0B43F · 강조·주요 버튼
밝은 회백색#F3F5F8 · 본문 바탕
  • 신규 CI의 남색·금색 기준 적용
  • 금색 글자는 남색 바탕에서만 사용 (밝은 바탕에서는 가독성 저하)

나. 서체

  • 제목: 블랙한산스 (굵고 힘 있는 한글 서체, 무료 사용 가능)
  • 본문: 본고딕(Noto Sans KR) (무료 사용 가능)

다. 로고

  • 기관 제공 신규 CI 사용, 형태 및 비율 변경 없음
  • 웹 적용을 위해 배경만 투명 처리

라. 이미지

  • 남색 나무 바닥 및 금색 코트 선을 공통 소재로 한 이미지 5종 사용
    • 첫 화면·문의 배경, 강조 문장 배경, 가치별 사물 이미지 3종(농구공, 호루라기, 운동화)
  • 사람 사진 미사용 (실제 활동으로 오인될 우려 방지)
  • 모든 이미지는 AI 생성 시안용 이미지임 (실제 활동 사진 아님)
  • 사용 가능한 실제 사진 제공 시 교체 또는 추가 예정

7. 검토 방법

  • 문구 변경: 시안에서 문구 클릭 → A·B·C 중 선택 또는 직접 수정
  • 일괄 변경: 화면 하단 막대에서 A·B·C 선택 시 전체 문구 변경
  • 수정 요청: 문구 클릭 → ‘이 문구에 수정 요청 남기기’ → GitHub 작성 화면에서 등록
  • 선택 결과 전달: 화면 하단 ‘선택 결과 보내기’ → 선택 내용이 자동 입력된 GitHub 작성 화면에서 등록
  • 의견 등록 시 GitHub 계정 로그인 필요 (무료 가입)
  • 선택한 문구는 보내기 전까지 사용 중인 브라우저에만 저장됨
  • GitHub 의견은 공개 게시물이므로 개인정보 및 비공개 자료 기재 금지

9. 진행 절차

단계내용담당
1. 검토디자인 정의서 및 시안 검토, 문구 선택, 의견 등록기관
2. 수정의견 반영 및 수정 시안 공유제작
3. 자료 반영확정 문구, 연락처, 법인 정보, 공시 자료 반영기관 · 제작
4. 최종 확인 및 공개최종 화면 확인 후 홈페이지 공개기관 · 제작
  • 단계별 일정은 협의 후 확정

10. 유의 사항

  • 본 문서 및 시안은 기관 확정 전 검토용임
  • 시안의 문구 및 정보는 확정 전 제안이며 변경될 수 있음
  • 경영공시 빈 목록은 자료 미등록 상태를 의미하며, 기관의 공시 이행 현황과 무관함
  • 신규 CI는 AI 제작물로, 최종본 여부 및 사용 범위 확인 필요
