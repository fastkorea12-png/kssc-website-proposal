# KSSC 홈페이지 디자인 정의서 · V3

2026-10-23 클라이언트 검토본 v1.0. 기관 최종 승인 전 제안입니다.

## 목적

기관 이해 → 사업·사례 확인 → 교육·협력·후원 문의, 그리고 공시자료 탐색으로 연결합니다.

## 콘셉트

선수의 경험이, 모두의 배움으로.
스포츠의 활동성, 사람 사이의 따뜻함, 기관의 신뢰감을 함께 표현합니다.

## 메뉴

KSSC 소개 / 주요사업 / 활동 이야기 / 소식·모집 / 공시·자료실 / 교육·협력 문의

## 주요 화면

- 메인: 대표 제목·설명·버튼·현장 이미지 → 3사업 → 활동 이야기 → 공시 바로가기 → 소식 → 참여 경로.
- 사업: 사업명 → 대상 → 활동 내용 → 진행 방식 → 사례 → 문의. 운영 조건은 확인 후 작성.
- 공시: 기부금 모금·활용실적 / 결산·재무자료 / 경영공시 / 정관·인증. 연도·검색·첨부·정정 이력 설계.
- 문의: 유형·이름·기관명(선택)·이메일·제목·내용. 실제 개인정보 처리와 수신 경로 확정 후 개발.

## 반응형·접근성

360/390/430px 모바일, 768px 태블릿, 1440px PC 검수. 메뉴·버튼·탭·폼·빈 상태 공통화. 키보드 탐색, 대체텍스트, 제목 계층과 대비 확인.

## 운영

공시자료 작성 → 회계·세무 검토 → 기관 승인 → 공개. 외부 제출과 홈페이지 게시 상태는 구분합니다. 적용 의무·서식·기한은 기관 지정 자료와 담당자 검토를 통해 확정합니다. 수정 이력·관리 권한·백업을 설계합니다.

## 준비자료

최신 로고 / 실제 사업·사례 / 게시 가능한 사진 / 법인 정보 / 지정·인증·정관 / 공개용 공시자료 / 문의 담당자 / 개인정보 처리 방식 / 도메인·운영 권한.

## 현재 가안과 후속 범위

현재는 반응형 화면과 탐색·입력 검증을 제공하는 정적 가안입니다. 문의 전송·저장, 관리자, 공시 첨부, 외부 연동은 미연결입니다. 실제 자료 반영과 기능 개발 후 공개정보·모바일·전송·첨부·관리자·백업을 검수합니다.
