## 댓글

항목별 GitHub Issues 스레드에서 댓글과 캡처를 남길 수 있습니다. 열람은 로그인 없이, 작성은 GitHub 로그인 후 가능합니다. 공개 공간이므로 개인정보와 비공개 자료는 올리지 않습니다.

## 검토 상태

- 기관 최종 승인 전 제안·가안입니다.
- 사업 분류·문구·로고 최신본 여부는 기관 확인이 필요합니다.
- 교육 이미지는 AI 참고 이미지이며 실제 KSSC 활동 사진이 아닙니다.
- 실제 문의 전송·저장, 관리자, 공시자료 첨부는 미연결입니다.
- 일정·예산·계약 범위는 협의 후 확정합니다.
