01디자인 콘셉트

선수의 경험이,
모두의 배움으로.

스포츠의 생동감, 사람 사이의 따뜻함, 기관의 신뢰감을 함께 표현합니다. 메인에서는 사람과 교육을 먼저 보여주고, 공시는 빠른 자료 탐색에 집중합니다.

  • 제목은 짧고 구체적으로, 본문은 확인된 사업 내용 중심으로 작성합니다.
  • 실제 활동과 참여자를 존중하는 사진을 사용합니다. 성과·후기·협력사 로고는 확인된 자료만 공개합니다.
  • 일반 방문자가 쉽게 이해할 수 있도록 법률·운영 용어를 과도하게 전면에 배치하지 않습니다.

04페이지별 화면 설계
메인 · 기관 이해에서 참여까지
  1. 첫 화면: 대표 제목·짧은 설명·문의/사업 버튼·교육 현장 이미지
  2. 대표 사업: 확인 전 구성안으로 제안한 세 가지 사업
  3. 활동 이야기: 실제 사진·대상·시기·확인된 변화
  4. 투명한 운영: 기부금 사용내역·결산경영공시 바로가기
  5. 소식·모집과 교육/협력/후원 참여 경로
메인 가안 열기 ↗
사업 상세 · 누구에게 무엇을 제공하는가

사업명 → 한 문장 소개 → 대상 → 실제 활동 내용 → 진행 방식 → 실제 사례 → 문의 순으로 구성합니다. 종목·지역·회차·시간·비용은 기관이 확인한 내용만 기재합니다.

05반응형과 공통 요소
  • 모바일 360·390·430px, 태블릿 768px, PC 1440px를 기준으로 검수합니다.
  • PC의 나란한 제목·이미지는 모바일에서 세로로 배치합니다. 메뉴는 모바일에서 열고 닫는 형태로 전환합니다.
  • 헤더·버튼·사업 카드·분류 탭·연도 필터·검색·빈 상태·입력 오류·푸터를 공통 요소로 관리합니다.
  • 키보드 탐색, 이미지 대체텍스트, 제목 계층, 색 대비와 동작 감소 설정을 확인합니다.
06공시·문의 운영 기준

홈페이지의 공개자료 게시와 외부 공시 시스템 제출 상태는 각각 관리하도록 제안합니다. 적용 의무와 서식·기한은 지정 자료·정관·결산 내용과 담당자의 검토를 거쳐 확정합니다.

  • 자료 작성 → 회계·세무 검토 → 기관 승인 → 공개의 흐름을 정합니다.
  • 공개용 파일의 개인정보를 확인하고, 수정 이력·권한·백업을 관리합니다.
  • 문의 수신자·저장 여부·보유기간·동의 안내를 실제 운영에 맞춰 확정합니다.
  • 공개 페이지와 검토 댓글에는 비공개 증빙·개인정보를 올리지 않습니다.
07필요자료와 오픈 검수

기관에서 확인할 자료

  • 최신 로고·사업 내용·대표 사례·게시 가능한 현장 사진
  • 최신 법인 정보·지정/인증 증빙·정관·공개용 공시자료
  • 문의 담당자·개인정보 처리 방식·도메인 관리·관리자 역할

공개 전 검수

모바일 화면, 링크와 첨부 다운로드, 실제 문의 전달과 실패 처리, 최신 공개정보, 개인정보 노출, 관리자 등록·정정과 백업 복원을 확인합니다.

현재 상태

시각 디자인과 주요 화면의 탐색·입력 검증을 확인할 수 있는 가안입니다. 운영 시스템 구축과 기관 최종 검수는 후속 단계입니다.
